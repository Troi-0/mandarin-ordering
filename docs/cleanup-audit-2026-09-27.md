# Unused-code cleanup audit — 2026-09-27

The audit covered tracked application/importer/scheduler source, package scripts,
TypeScript and Vite/Vitest configuration, workflows, static assets, CSS selectors,
menu archives, benchmark fixtures, and the GitHub default branch/workflow states.
TypeScript symbol references and repository searches were checked together; code
used by tests or framework entrypoints was not classified as unused solely because
it lacked a production import.

## Confirmed cleanup

- Removed the unused `MenuCategory` and `MenuPublication` type aliases.
- Made 22 declarations module-private because no other module imports them. Their
  definitions and internal use remain, including validation schemas, data types,
  Sofia-hour calculation, and currency formatting.
- Moved the test-only `extractFacebookCandidatesFromJsonScripts` projection into
  the Facebook parser test file. Production already calls `inspectFacebookFeed`
  directly, and the same parser assertions continue to exercise it.
- Removed the duplicate `src/vite-env.d.ts` directive and its coverage exclusion.
  `tsconfig.app.json` already explicitly includes `vite/client` in `types`.

## Checked and retained

- All three runtime dependencies (`react`, `react-dom`, `zod`) are used. Development
  dependencies support builds, lint, tests/coverage, importer execution, browser
  scraping, or TypeScript declarations; none was confirmed unused.
- The five remaining workflows serve CI, Pages deployment, Facebook import,
  manual-inbox import, and manual Gemini benchmarking. An infrequent or failed
  benchmark is not evidence that the recovery tooling is obsolete.
- All public image/icon assets are referenced by `index.html`. `.nojekyll` is a
  Pages convention, not an imported module.
- CSS classes absent from literal source (`notice--error`, `notice--success`) are
  generated by the `notice--${notice.kind}` template and remain in use.
- Historical menu JSON is validated by `scripts/validate-menus.ts`; archived
  images/reference menus support reproducible OCR benchmarks, and review drafts
  retain rejected extraction evidence.
- Worker entrypoints, runtime types, and exported test seams remain. No Worker
  source/configuration, secrets, infrastructure, or schedule is changed.
- The unrelated untracked `CLAUDE.md` was preserved and excluded from the commit.

Validation passed the existing full `npm run check` gate on Node 24.19.0:
129 root tests, 87 scheduler unit tests, and 3 workerd tests (219 total), coverage
thresholds, zero-cost validation, lint, typechecks, app build, and dry-run Worker
bundle. The compiled application JavaScript and CSS are byte-for-byte identical
to the pre-cleanup build.
